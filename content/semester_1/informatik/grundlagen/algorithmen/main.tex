\section{Algorithmus} 
Ein Algorithmus ist eine Lösungsweg der ein gegebenes Problem endlich und deterministisch Lösen kann.
\ankinote{definition}{Definition}{Endlicher, deterministischer Lösungsweg}

Algorithmen können als Code implementiert, als Pseudocode dargestellt oder grafisch dargestellt werden.
